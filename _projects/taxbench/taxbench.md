TaxBench assesses whether agents can accurately prepare 2025 tax returns, identify missing taxpayer information, and apply the appropriate rules when multiple provisions apply to the same field. Built from structured, deterministic tax rules and realistic scenarios with expert-reviewed reference returns.

- **500+** tax rules
- **50+** realistic scenarios
- Reference returns with expert review in progress
