Prepared November 3, 2026

Five existing DAPLab publication entries point to preprints. This handoff lists
the replacement fields for the versions of record.

Open https://daplab.cs.columbia.edu/admin/ and select Papers, then Published
papers. A publication reviewer or site admin can locate each entry by its
current title or URL, select Edit, apply the listed fields, and save the changes.
The DOI link goes in the Paper URL field.

The live site reads publication records from Convex. Apply these corrections
through the admin portal to publish them.
